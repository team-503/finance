# Markdown: один абзац — один рядок

Не розривай абзац переносами рядка. Абзац пишеться суцільним рядком, хай яким довгим — перенос робить редактор, а не ти.

Погано:

```md
**`@repo/types` — компільований пакет.** Він віддає `dist` через `tsc`; споживачі
читають `dist/*.d.ts`, а не сирці. Збирай його.
```

Добре:

```md
**`@repo/types` — компільований пакет.** Він віддає `dist` через `tsc`; споживачі читають `dist/*.d.ts`, а не сирці. Збирай його.
```

Причина проста: у зібраному вигляді перенос усе одно зникає, а в сирці лишається рваний текст, який неможливо відредагувати без переверстки всього абзацу. Різниця в diff теж стає нечитабельною — правка одного слова зсуває всі наступні рядки.

Перенос рядка ставиться лише там, де він щось означає: між абзацами, у списках, у таблицях, у блоках коду.

Це стосується всього маркдауну: скіли, правила, README, описи PR, коментарі до задач.
